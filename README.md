# ProfitPilot AI — Landing Page

Static, dependency-free website ready for free hosting.

## Files
- `index.html` — landing page
- `style.css` — responsive styling
- `privacy.html` — privacy page
- `terms.html` — terms page

## Free deployment
Upload this folder to a GitHub repository and import the repository into Vercel, or deploy it with another static host.

## Important before production
Replace `hello@profitpilot.ai` with an email address you control.
Review the Privacy Policy and Terms with a qualified professional before using them for a public production service.

## Salla
Use the deployed HTTPS homepage as the App Website URL in Salla Partners. Salla's current app creation documentation requires an App Website URL.
